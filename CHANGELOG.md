# Changelog

## v0.1.0

[Compare changes](https://github.com/stacksjs/ts-presentation/compare/f1e0d8e3e034bc72fd147424acea3ed0fece6112...v0.1.0)

- Create and serve Markdown presentations with the Bun CLI and STX components. Use presenter notes, timers, progressive reveals, drawing tools, and the slide editor.
- Export to PDF, PNG, Markdown, or PowerPoint. Editable PowerPoint preserves supported text, equations, charts, and shapes.
- Render Gantt schedules, GitGraph histories, flowcharts, and other diagrams with ts-charts. Support native MathML, scoped TeX macros, and chemistry notation.
- Use themes, addons, and live code in decks. The package includes deck and theme scaffolds.
- Verify the 398 ported cases from all 41 Slidev v53.1.0 test suites in Bun.

Based on Slidev by Anthony Fu and the Slidev contributors. See the repository licenses for attribution.
